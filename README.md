Sunt colorist și realizator de film. Construiesc uneltele de care am nevoie la etalonaj și în postproducție — apoi le fac disponibile și altora.

## GDC STYLE

Instrumente de culoare **OpenFX pentru DaVinci Resolve**, grupate pe pipeline-ul proiectului: ACES, DaVinci Intermediate, ARRI LogC3 sau LogC4. Include lanțul de la transformarea de intrare până la DRT, biblioteca creativă GDC Cinema Style (86 de stiluri de film) și integrarea Stream Deck. Ediția Demo, cu filigran, se poate încerca fără licență; versiunea Full se activează cu licență. macOS 13+, versiunea curentă 2.6.0.
