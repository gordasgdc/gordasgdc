I'm a colorist and filmmaker. I build the tools I need for grading and post-production — then make them available to others.

## GDC STYLE

**OpenFX colour tools for DaVinci Resolve**, grouped by project pipeline: ACES, DaVinci Intermediate, ARRI LogC3 or LogC4. It covers the chain from input transform to DRT, the GDC Cinema Style creative library (86 film styles) and Stream Deck integration. The watermarked Demo edition can be tried without a licence; Full is activated with one. macOS 13+, current version 2.6.0.

**[Official page and download → gordas.dev/gdc-style-client](https://gordas.dev/gdc-style-client/)**
