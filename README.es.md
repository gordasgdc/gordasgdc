Soy colorista y realizador. Construyo las herramientas que necesito para el etalonaje y la posproducción — y después las pongo a disposición de otros.

## GDC STYLE

Herramientas de color **OpenFX para DaVinci Resolve**, agrupadas por el pipeline del proyecto: ACES, DaVinci Intermediate, ARRI LogC3 o LogC4. Incluye la cadena desde la transformación de entrada hasta el DRT, la biblioteca creativa GDC Cinema Style (86 estilos de película) y la integración con Stream Deck. La edición Demo, con marca de agua, se puede probar sin licencia; la versión Full se activa con una licencia. macOS 13+, versión actual 2.6.0.

**[Página oficial y descarga → gordas.dev/gdc-style-client](https://gordas.dev/gdc-style-client/)**
